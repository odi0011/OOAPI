# 资金费套利 / 现货-永续基差 carry 回测报告

样本：2026-04-20 → 2026-10-17，180 天，8 币（KORU 无现货市场，剔除）。
前 120 天校准 / 后 60 天留出，留出期不参与任何选择。

## 0. 结论摘要

| 项目 | 结果 |
|---|---|
| 主策略 A（全程持有，taker，3x） | 毛资金费 +171.1 bp，成本 39.7 bp，净 **+133.0 bp / 180 天**（名义） |
| 年化（名义 / 总资本 3x / 仅保证金 3x） | 2.72% / **2.03%** / 8.26% |
| 校准期 120 天 | 净 +61.2 bp，年化总资本 0.93% |
| 留出期 60 天 | 净 +71.8 bp，年化总资本 3.31% |
| 逐币种留出期 | **8/8 全部为正**（+53.4 ~ +107.1 bp） |
| 最大回撤（总资本，3x） | −0.15% |
| 正收益月份 | 4/7（57.1%）；留出期 2/3 |
| B 阈值变体 | 全部为负；最差 −2920.6 bp |
| C 排序变体 | 全部低于 A；8h 调仓版 −254.5 bp |

**判定：不通过（经济上）。** 净收益真实、留出期成立，但总资本年化仅
2.0–2.3%；现货腿占满资本，加杠杆无法突破名义年化 2.72%，一年摊薄
一次性成本后上限约 3.1%，低于约 4% 的现金 hurdle。

**重新评估条件**：组合平均资金费持续 ≥0.44 bp/8h（约 4.8% 年化毛收入）；
或现货腿额外获得 ≥2% 年化 staking/lending；或有 maker rebate / 组合保证金；
或资金费横截面出现明显持续性。

## 1. 数据与方法

| 数据 | 来源 | 覆盖 |
|---|---|---|
| 现货 1h K 线 | `api.binance.com/api/v3/klines` | 2026-04-18 → 10-17，每币 4,373 根 |
| 永续 1h K 线 | `fapi.binance.com/fapi/v1/klines` | 同上 |
| 资金费 | `fapi.binance.com/fapi/v1/fundingRate` | 每币 547 个 8h 点 |

模拟：8h 网格，541 个结算点。每币名义 $1，现货多 + 永续空等名义；
持有期内不做 delta 再平衡；资金费按当时永续名义结算；信号只用
结算点及之前的数据；组合 8 币等权，未激活的币保持现金。

成本（主口径）：现货 taker 10bp/边、永续 taker 5bp/边、滑点 2bp/腿/边
→ 单边 19bp、往返 38bp。maker 口径：永续 2bp/边 → 往返 32bp。
实际 A 平均往返 39.7bp（平仓名义漂移）。

变体：
- A 全程持有。
- B 上次结算资金费 > 阈值（0 / 0.005% / 0.01% / 0.02%）才持有。
- C 7 天滚动平均资金费排序，持有前 2/3；8h / 周 / 月调仓；
  另做校准期选币的静态版本。

均值回归。不是调参能解决的。

## 7. 杠杆与清算

| 杠杆/口径 | 年化名义 | 年化总资本 |
|---|---:|---:|
| 3x | 2.72% | 2.03% |
| 5x | 2.72% | 2.26% |
| 1x 组合保证金 | 2.72% | 2.72% |
| 1.42x（LINK 约束下的无补保安全杠杆） | 2.72% | 1.59% |

现货腿占用 100% 名义，总资本回报上限就是名义回报 2.72%；加杠杆
只把 2.03% 提到 2.26%。隔离保证金且不补保时，LINK 70% 上涨会在
1.42x 以上爆仓、SOL 2.05x、BNB 3.29x；3x/5x 在这几个币上并不安全。

## 9. 多重检验

9 个策略实现 × 2 个费用模式 = 18 个，全部报告；另做 BNB 折扣、
3 个基差情景、2 个杠杆、2 个回报口径的敏感性。A 是预先设定的基线，
不是从 18 个里挑出来的。留出期未参与任何选择。

## 10. 局限

1. 单一样本、单一 regime（180 天，资金费多数为正，上限 1bp/8h）。
2. B 用上次已实现资金费作为预测，未用 premium index/predicted funding。
3. 成交按 8h 结算点 1h open，未建模延迟、部分成交、盘口深度。
4. maker 假设稳定成交，未建模排队与逆向选择。
5. 主结果假设现货与永续可统一管理；隔离保证金下受第 7 节约束。
6. 无反向 carry（需要借币）；负费率期是纯拖累。
7. 未计现货 staking/lending 收益、税费、托管与对手方风险。
8. KORU 无现货市场，剔除。

## 11. 工程建议

**不值得作为独立策略投入工程资源。** 回报绝对值太低（2–3% 年化），
上限被现货腿锁死，清算/保证金前提苛刻，B/C 失败是结构性的。
若只是想做低波动现金替代，直接持有 USDT/T-bill 收益更高、运维更简单。
