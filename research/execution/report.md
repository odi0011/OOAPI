# 执行成本研究：市价 vs post-only maker 入场

生成：`python research/execution/exec_sim.py`。数据：Binance USDT-M 180 天（2026-04-20 → 2026-10-17），8 币（KORU 剔除）。120 天校准 / 60 天留出，参数固定不搜索。

## 0. 结论

**maker 入场把往返成本从 14bp 降到 9bp（省 5bp），但不够翻正。**

把三类信号、8 个币、两个验证段合在一起看：

- 市价基准（按笔加权，EMA+RSI 15m 笔数占多数）：13673 笔，均值 -14.44bp/笔；三个策略等权平均 -8.65bp/笔。
- B（post-only 挂 close，N=3）：12934 笔，均值 -10.50bp/笔；三个策略等权平均 -4.48bp/笔。
- B 相对市价：按笔加权 +3.93bp/笔，等权 +4.17bp/笔。机械成本节省是 +5bp，但只实现约 +4bp：EMA 两个策略约 89% 的交易以固定百分比 TP/止损出场，更好的入场价同时把 TP/止损位也挪动，百分比收益不变，滑点节省和价格改善被抵消，只有 3bp 的费率差直接落地；唐奇安中轨出场是价格信号出场，退出价与入场价无关，拿满 +5bp。B 的成交率接近 100%，所以差额不是成交样本选择，而是出场路径。
- 但 B 的等权净期望仍是 -4.48bp/笔（市价 -8.65bp/笔）；这个等权值被唐奇安留出段的 +29.4bp 拉高，剔除该单元后其余 5 个策略-段单元平均 -11.26bp/笔。成本改善是真实的，只是毛 edge 太负。

分策略的结论见第 2 节；关键诊断（成交率、逆向选择、配对改善）见第 3 节。

### 1.2 四种入场执行

| 代号 | 入场 | 入场成本 | 出场成本 |
|---|---|---|---|
| A 市价 | 信号下一根开盘 | taker 5bp + 滑点 2bp | taker 5bp + 滑点 2bp |
| B post-only | 挂在信号收盘价（多=close，空=close），未来 N 根 low/high 触及才成交，N 根未成交撤单 | maker 2bp，无滑点 | 同上 |
| C 更保守限价 | 挂在 close∓0.1%，未来 N 根触及才成交 | maker 2bp，无滑点 | 同上 |
| D 市价+BNB/VIP | 同 A，仅费用敏感性 | taker 4.5bp（BNB 9 折）或 4bp（VIP 8 折） | 同上 |

所有出场（含止损）一律 taker 5bp + 2bp 滑点，因此：

- 市价往返 = 5 + 2 + 5 + 2 = **14bp**
- maker 入场往返 = 2 + 5 + 2 = **9bp**（省 5bp）
- maker 0 费敏感性 = 0 + 5 + 2 = **7bp**
- BNB 9 折市价往返 = 4.5 + 2 + 4.5 + 2 = **13bp**

限价成交价按挂单价计（不假设价格改善）；跳空穿过挂单价也按挂单价成交。`pen1bp` 变体要求价格再穿透 1bp 才算成交，作为排队位置假设的稳健性检查。限价在成交当根不使用该根 high/low 判止损（无法知道极值在成交前还是后），信号类出场仍可在成交当根收盘触发、下一根开盘执行。

### 1.3 逆向选择

对每一笔成交记录两个方向调整后的价格变动：

- `成交当根`: 从成交价到成交当根收盘的方向收益；
- `成交后下一根`: 成交后下一根的 close-to-close 方向收益。

把限价成交样本与“同一批信号的市价反事实”比较（相同信号、相同出场规则），再与全部市价信号比较，分离：

- `adv_*`: 同一信号下，限价成交时点与市价入场时点的差异（逆向选择/价格路径）；
- `sample_sel_*`: 能成交的信号本身与全部信号的质量差异（成交样本选择）。

P&L 上，每笔限价成交都与同一信号的市价反事实做配对，`matched_exec_gain_bp = net(limit) − net(market cf)`，直接给出扣掉逆向选择后的真实改善。

### 5.1 四个直接问题

1. **往返成本从 14bp 降到多少？** maker 2bp 入场 + taker 5bp 出场 + 2bp 出场滑点 = **9bp**，机械节省 **5bp/笔**。若 maker 费为 0（返佣假设）则为 **7bp**；市价 + BNB 9 折为 **13bp**，市价 + VIP 8 折为 **12bp**。
2. **成交率多少？** post-only 挂信号收盘价（B）：独立成交率约 99.6%–100.0%（N=3；N=1/6 几乎相同，因为绝大多数成交发生在信号后第 1 根）。挂 close∓0.1%（C）的成交率随策略和 N 变化：EMA 交叉 N=3 约 92.4%，EMA+RSI 15m N=3 约 80.5%。完整数字见表 3.1。
3. **逆向选择吃掉多少？** 分两种：(a) 成交后的价格继续朝不利方向走——B 的成交当根平均 -0.6 到 -5.8bp，但市价反事实在同一根也经历同样走势，所以相对逆向选择≈0；(b) 只成交更差的信号——C 的 `成交样本选择bp` 为 **-5 到 -8bp**，即 10bp 挂单价格优势中有 5–8bp 被“成交的都是坏信号”吃掉。B 的成交率接近 100%，这一项≈0；C 的成交率 61–95%，样本选择是主要代价。
4. **净期望改善多少？** B 平均 **+4.17bp/笔**（同信号配对改善 +4.36bp，成交样本选择 -0.19bp）；C 平均 **+7.13bp/笔**（同信号配对改善 +13.79bp，成交样本选择 -6.67bp）。C 的设计优势是 15bp（10bp 挂单偏移 + 5bp 费用/滑点），但固定百分比 TP/止损出场只能直接兑现 3bp 费率差，价格偏移主要靠信号类出场兑现；再叠加成交样本选择，最终只剩约 7bp。完整分解见表 3.3。

### 5.2 判定

- 校准段 B N=3：净期望为正 0/3 个策略，由负翻正 0/3 个；平均改善 +4.39bp/笔（配对 +4.42bp）。逐策略：ema_cross_9_21: -13.8→-9.4bp; donchian55_mid: -23.9→-18.9bp; ema_rsi_12_26: -17.2→-13.3bp。
- 校准段 C N=3：净期望为正 0/3 个策略，由负翻正 0/3 个；平均改善 +7.81bp/笔（配对 +14.72bp）。逐策略：ema_cross_9_21: -13.8→-6.3bp; donchian55_mid: -23.9→-14.4bp; ema_rsi_12_26: -17.2→-10.8bp。
- 留出段 B N=3：净期望为正 1/3 个策略，由负翻正 0/3 个；平均改善 +3.95bp/笔（配对 +4.29bp）。逐策略：ema_cross_9_21: -11.2→-6.9bp; donchian55_mid: +25.8→+29.4bp; ema_rsi_12_26: -11.7→-7.7bp。
- 留出段 C N=3：净期望为正 1/3 个策略，由负翻正 0/3 个；平均改善 +6.44bp/笔（配对 +12.87bp）。逐策略：ema_cross_9_21: -11.2→-6.6bp; donchian55_mid: +25.8→+34.9bp; ema_rsi_12_26: -11.7→-6.1bp。

**结论：不够。** maker 入场把 14bp 往返压到 9bp，实测净期望改善 B 约 +4.2bp/笔、C 约 +7.1bp/笔；但三个主信号里，EMA(9/21) 1h 和 EMA(12/26)+RSI 15m 在 120 天校准段和 60 天留出段都没有翻正。唐奇安 N=55 1h 的留出段为正，但市价基准本来就为正（+25.8bp），maker 只是把它推到 +29.4bp；154 笔、t≈0.57、8 个币里 2 个为负，这是 regime 暴露而不是执行改善，不能当成 maker 的功劳。

根本原因没有变：把 14bp 市价成本加回去，EMA 交叉和 EMA+RSI 的毛 edge 只有约 **-3 到 +3bp/笔**（市价净期望 -11 到 -17bp + 14bp）。maker 入场后往返成本是 9bp，所以要翻正，毛 edge 必须超过 9bp/笔；当前差 6–12bp。maker 省下的 4–5bp 是真的，但补不上这个缺口。

两个附带发现：

1. post-only 挂在信号收盘价（B）的成交率高得惊人（N=1 就约 99%），因为下一根 K 线的 low/high 几乎总会碰到上一根收盘价。这意味着 B 更像“用 maker 费率在上一根收盘价入场”，而不是“等一个更好的价格”。它的 4–5bp 改善几乎全部来自费率/滑点，而不是价格改善。真正想拿价格优势必须挂得更远（C），但挂得越远，成交样本的逆向选择越重。
2. 固定百分比 TP/止损会把 maker 的价格优势抵掉一部分：更好的入场价同时也移动了 TP/止损位，触发时百分比收益不变，滑点和价格改善被抵消，只有 3bp 费率差直接落地；但更好的入场价会改变触发概率（可能避免一次止损），这部分路径效应方向不定。因此 maker 入场对“信号出场”策略（唐奇安中轨、反向交叉）比对“固定 TP/止损”策略更可预测：前者能全额兑现价格改善，后者只能兑现一部分。当前 EMA 策略 89% 的交易走 TP/止损，所以 C 的 10bp 价格优势只有一部分兑现。
