乐乐 Agent 工具清单

23 个工具组 · 200 个业务方法

包括原有 21 项与新增 179 项。另有 platform.catalog / platform.describe，以及 15 个平台工具组的 describe，用来发现方法和查询参数。

普通用户操作自己的资源；管理方法按管理员和超级管理员权限开放。写入操作先展示目标与完整内容，确认后执行一次。拒绝、超时、失败均不会冒称完成。

模型清单来自当前密钥真正可用的模型目录，可按关键词、厂商分页查询，和历史调用记录分开。

凭据绑定、密码修改、密钥明文查看、文件选择与上传仍在对应页面完成；Agent 可以引用本人已上传媒体。编排权限配置、批准另一个工具请求不向 Agent 开放。平台未实现的能力不列为可执行工具。交易方法沿用账户交易模式和风控，真实资金操作需要明确内容确认。
