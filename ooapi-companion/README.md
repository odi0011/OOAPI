# OOAPI 本地执行器

需要 Node.js 18 或更高版本。下载 ZIP 并解压，无需安装 npm 依赖。云端负责模型与任务编排；此程序主动连接云端，在你授权的本机目录执行文件操作。

## 配对与启动

在终端运行（把服务地址和目录换为自己的值）：

```sh
node ooapi-companion/start.mjs --server https://你的平台 --root "/本机项目目录" --label "项目简称"
```

在已登录平台的「本地工作区」填入终端显示的一次性配对码，有效期 5 分钟。核对终端显示的账号编号，再在对话中选择这个工作区。配对码仅用于关联设备；设备 bearer 保存在本机，不会打印。标签不要填写绝对路径。

默认只授权读取。需要修改文件时，启动命令增加 `--allow-write`。管理员身份不会自动赋予本机的写入或命令权限；修改本地授权需重新配对。

已有配置重连：

```sh
node ooapi-companion/start.mjs
```

可用 `--state-dir "/私有状态目录"` 更换配置、执行日志和检查点的位置。状态目录必须位于授权项目之外。不要把此目录提交到 Git 或分享给他人。POSIX 系统使用目录 0700、文件 0600；Windows 请确保目录的系统访问权限只允许你的账号和系统管理员。

## 命令执行

先自行安装并启动 Docker，准备已有的 Linux 镜像。执行器不会下载镜像。授权示例：

```sh
node ooapi-companion/start.mjs --server https://你的平台 --root "/本机项目目录" --allow-write --allow-exec --docker-image 已安装的镜像名
```

仅支持本机 Docker Linux 引擎，拒绝远程 Docker 地址。命令在镜像内的 `/bin/sh` 执行，工作区挂载到 `/workspace`；禁止网络，限制 CPU、内存、进程数，使用非 root 身份，容器根文件系统只读。未授权写入时，项目挂载也是只读。镜像须包含所需工具，依赖须提前准备；没有 Docker、合适镜像或运行权限时，命令能力会显示不可用，绝不会退回本机 shell。

命令默认限时 120 秒，可设置最高 30 分钟。停止或超时会终止调用并删除容器。容器命令可以读取整个授权项目，包括项目内已有的配置文件；文件工具对 `.env`、密钥文件等的过滤不等于 Docker 的秘密隔离。仅授权你愿意让模型访问的目录，避免在其中放真实凭据。

## 文件与状态

文件工具支持列目录、读取文本、字面文本搜索、写入及 1–50 项顺序文本替换。每项须恰好匹配一次，所有替换在内存完成后统一写入；任一项无效则整组不写。路径必须是授权目录内的相对路径，拒绝符号链接、目录联接、上级跳转和受保护文件；文本最大 256 KB。更新已有文件须使用读取结果的 `expectedSha256`，新增文件显式传 `null`，版本变化会拒绝覆盖。写入后重新读取核对哈希，只有真实读回一致才返回已核验；提交后读回失败或内容变化会记为结果未确认，不能自动重跑。

同一工作区的项目操作串行执行。范围校验和版本核对不构成对恶意本机进程的内核级隔离；不要让不受信任程序同时改动授权目录。

每个调用编号的开始和完成状态先写本机日志。网络断线后自动重连，同一编号的完成调用返回旧结果，不会再次写文件或执行命令。如果进程在完成记录前退出，会标记「结果未确认」，阻止自动重跑副作用操作，需要你核对本机现状。任务恢复还会读取本机检查点；不要随意删除状态目录。

在网页可暂停、停止任务和撤销设备；终端按 Ctrl+C 可关闭执行器。暂停不会回滚已经完成的操作。已派发操作在取消、断线或撤销时可能已经产生副作用，恢复前应核对日志和文件。重新配对产生新设备身份，旧设备可在网页撤销。

## 数据边界

云库仅保存设备/工作区标识、账号和会话关联、设备凭据哈希及任务控制信息。绝对根路径、运行器读取的文件内容、命令输出和包含这些内容的完整任务检查点保存在本机。工具请求和结果在连接期间经 HTTPS 临时传输，云端模型会收到完成任务所需的片段；这不是完全离线或数据永不离开设备的模式。你主动输入的对话、补充说明可以作为普通对话存云。聊天里的「添加附件」仍是普通云端上传；需要文件留在本机时，使用工作区连接和运行器读取。

单次传输最大 4 MB，本机检查点最大 3 MB。执行器主动 HTTPS 长轮询，无需开放本机入站端口。HTTP 仅支持显式 `--allow-http-localhost` 的本机开发；不要对公网使用这个选项。
